# 0.12.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Narrow the authority of repository instruction files, separate the plugin's ship, verify, and review from Claude Code's built-ins, make the hook read its input as UTF-8, and prove the release on Claude Code 2.1.332.

**Architecture:** Most of the release is wording, in the router skill, three skill descriptions, the README, and the hook's messages. Each part is pinned by a unit test in `scripts/test_skills.py` or `scripts/test_edit_guard.py`. One behavior case, `agents-md`, is new. One hook change is new: decoding stdin. A manual probe and one paid suite run close the release.

**Tech Stack:** Python 3 standard library (`unittest`), Markdown skills, `claude plugin eval` (Claude Code 2.1.332, WSL2).

**Spec:** `docs/superpowers/specs/2026-11-27-release-0-12-0-design.md`

## Global Constraints

- Skill `name` fields stay unchanged (`ai-native-*`); no rename (owner decision, 2026-11-27).
- Every `SKILL.md` stays under 15,000 bytes (`test_skill_fits_after_compaction`). The router is 9,389 bytes now.
- A skill `description` is at most 1024 characters (Agent Skills spec).
- No `"onFailure": "block"` in `.claude-plugin/hooks.json` (ADR-003).
- Fixture repositories: the Git identity and commit message must not contain the words fixture, test, eval, or sample (ADR-010).
- An edit to the router's Invariants section changes the digest. Record the new digest in `docs/tracking/ARCHITECTURE.md` once, after Tasks 3 and 4 are both done.
- `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` both go to `0.12.0`. The changelog entry stays `## 0.12.0 - Unreleased` until the suite has run.
- Suite cost ceiling: `--max-cost-usd 25`. The expected cost is about $22.
- Use the repo's changelog at `docs/changelogs/CHANGELOG.md`, not `docs/tracking/CHANGELOG.md`.

## Review Focus

1. A repository whose `CLAUDE.md` names a normal build step (`make test`, `pnpm install` from the lockfile) must get no new question. The trust sentence keys on downloads, unread scripts, and agent-config changes only. Task 3's test pins the scoping words.
2. Hook input on native Windows can hold non-ASCII text, such as a path with `ō` (UTF-8 `C5 8D`; `0x8D` has no cp1252 mapping). The hook must decide and must not fail. Task 1.
3. A caller that feeds the hook a text stream without `.buffer` (the existing `test_guard_failure` helper does this with `io.StringIO`) must still work. Task 1 updates the helper and reads `sys.stdin.buffer` only.
4. A session that ran the built-in `verify` and then writes `status: verified` must get a message that names `ai-native-sdlc:ai-native-verify` and says the built-in does not count. Task 2.
5. An agent may read the planted setup script before running it, which defeats the "unread" wording. The script therefore changes agent configuration, which is barred whether read or not. Task 5.

### Task 1: Hook reads stdin as UTF-8

**Files:**
- Modify: `hooks/edit_guard.py:696` (in `main()`)
- Test: `scripts/test_edit_guard.py` (`test_guard_failure` helper `run`, plus a new test)

**Interfaces:**
- Produces: `main()` reads `json.loads(sys.stdin.buffer.read().decode('utf-8'))`. No other signature changes.

- [ ] **Step 1: Write the failing test** `test_non_ascii_input_on_a_code_page_stdin` in `EditGuardTest`. Build an Edit event whose `file_path` is `str(Path(folder) / 'ō.py')`.  
  ```python
  self.assertNotIn('UnicodeDecodeError', out + err)
  self.assertNotIn('guard failed', out)
  self.assertEqual(json.loads(out)['hookSpecificOutput']['permissionDecision'], 'deny')  # no plan approval
  ```
- [ ] **Step 2: Run it and confirm it fails**
  Run: `python -m unittest scripts.test_edit_guard.EditGuardTest.test_non_ascii_input_on_a_code_page_stdin -v`
  Expected: FAIL. The output holds `guard failed` or `UnicodeDecodeError`.
- [ ] **Step 3: Implement the change in `main()`.** Replace `json.load(sys.stdin)` with the `Produces` line. In `test_guard_failure.run`, change `io.StringIO(aInput)` to `io.TextIOWrapper(io.BytesIO(aInput.encode('utf-8')), encoding='utf-8')`.
- [ ] **Step 4: Run the hook tests**
